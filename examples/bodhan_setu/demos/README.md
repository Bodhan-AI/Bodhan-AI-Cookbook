# Bodhan Setu live synthetic demos

These runs used the existing public synthetic fixtures from the Hugging Face evaluation dataset and the task-agent CLI (`python -m bodhan_agent`). Paid model calls were dry-run estimated by the agent and bounded by each run’s `--max-cost-inr`. The planner was the locally configured `lfm2.5:8b`; Bodhan results and reported costs are taken from each run report. Cache-hit cases are identified explicitly.

## Notes and limits

- The OCR and inline-translation cache-hit runs exercise the real task agent and cached Bodhan results, but are not fresh Bodhan API calls.
- The multi-page chapter-to-Tamil-audio attempt did not finish: OCR and translation completed, then the planner stopped before synthesis. The short audio-to-audio attempt produced a WAV but its back-transcription verification failed. These are retained as exploratory traces under the ignored local `eval-results/demo-diagnostics/` folder and are not counted among the demos above.
- A first TTS attempt exposed mojibake in the planner’s synthesis arguments and a report-writing crash on a null verification detail. Those were fixed before the successful TTS run listed above.
- Translation quality checks use an LLM reviewer and are advisory; they are not native-speaker certification.
- Generated WAV files are in each run’s `artifacts/` directory. The successful TTS output is AI-generated and must be labeled as such when shared.
