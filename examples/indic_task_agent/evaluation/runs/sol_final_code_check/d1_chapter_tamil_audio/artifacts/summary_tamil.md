ஐந்தாம் அத்தியாயம், ஒரு நீர்த்துளியின் பயணம், நீர் எவ்வாறு பூமியைச் சுற்றித் தொடர்ந்து நகர்கிறது என்பதை விளக்குகிறது. சூரியனின் வெப்பம் மற்றும் ஈர்ப்பு விசையால் இயக்கப்படும் நீரின் சுழற்சிக்கு ஆரம்பமோ முடிவோ இல்லை.

முதலில் சூரிய ஒளி கடல்கள், ஏரிகள் மற்றும் நதிகளை வெப்பமாக்குகிறது, சில நீரை கண்ணுக்கு தெரியாத நீராவி ஆக மாற்றுகிறது. இது ஆவியாதல் ஆகும். தாவரங்களும் அவற்றின் இலைகள் மூலம் நீராவி வெளியிடுகின்றன, இந்த செயல்முறை நீராவிப்போக்கு என்று அழைக்கப்படுகிறது.

ஈரப்பதமான காற்று மேலேறி குளிர்ச்சியடையும்போது, நீராவி தூசுத் துகள்களைச் சுற்றி சிறிய துளிகளாகக் குளிர்ந்து மேகங்களை உருவாக்குகிறது. இந்தத் துளிகள் கனமாகும்போது, நீர் மழை, பனி அல்லது ஆலங்கட்டிப் பொழிவாக பூமியில் திரும்புகிறது. இதுவே மழைப்பொழிவு ஆகும். இந்தியாவில், தென்மேற்கு பருவக்காற்று ஆண்டின் பெரும்பாலான மழையை வழங்குகிறது.

மழைநீர் குளங்கள், ஏரிகள், ஓடைகள் மற்றும் ஆறுகளில் சேகரிக்கப்பட்டு இறுதியில் கடலுக்குத் திரும்புகிறது. சில நிலத்தடிக்குள் கசிந்து கிணறுகள் மற்றும் நீரூற்றுகளுக்கு நீர் வழங்கும் நிலத்தடி நீரை நிரப்புகிறது மற்றும் விவசாயத்தை ஆதரிக்கிறது.

நீர் சுழற்சி நன்னீரை வழங்குகிறது, வானிலையை பாதிக்கிறது மற்றும் வெப்பத்தை விநியோகிக்கிறது. பூமியின் நீரில் சுமார் மூன்று சதவீதம் மட்டுமே நன்னீர் ஆகும், அதில் பெரும்பாலானவை உறைந்த நிலையில் உள்ளன, எனவே பாதுகாப்பு முக்கியமானது. காடுகள் வளிமண்டலத்திற்கு ஈரப்பதத்தை திரும்பவும் கொண்டு வர உதவுகின்றன.

பல் துலக்கும்போது குழாய்களை மூடி வைப்பதன் மூலமும், கசிவுகளை சரிசெய்வதன் மூலமும், மழைநீரை சேகரிப்பதன் மூலமும், காய்கறிகளை கழுவிய நீரை தாவரங்களுக்கு மறுபயன்பாடு செய்வதன் மூலமும் நாம் தண்ணீரைப் பாதுகாக்கலாம். இந்த அத்தியாயத்தின் மைய செய்தி எளிமையானது: தண்ணீர் தொடர்ந்து சுழன்று கொண்டே இருக்கிறது, ஆனால் பயன்படுத்தக்கூடிய நன்னீர் விலைமதிப்பற்றது. ஒவ்வொரு துளியும் கவனிக்கப்பட வேண்டும்.
