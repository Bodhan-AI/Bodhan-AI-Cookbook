# Demo inputs

Media files are **not committed**. Generate them (a few KB to a few hundred KB each) with:

```bash
python scripts/make_demo_inputs.py            # all inputs; the audio costs about Rs 1 once, then it is cached
python scripts/make_demo_inputs.py --no-audio # images, PDF, video and text only (free)
```

| Folder | Content | How it is made | Used by task |
|---|---|---|---|
| `01_scan_page/` | `scan_page_hindi.png`: a short Hindi paragraph, photo-style | HTML rendered by headless Edge/Chrome/Chromium, then slight rotation + noise | Tamil audio summary of a page |
| `02_voice_note/` | `voice_note_hindi.wav` (about 10 s) | English text → `translate_text` → `synthesize_speech` (our own tools) | Hindi voice note → English SRT |
| `03_worksheet/` | `worksheet_photo.png`: English worksheet with a price table | rendered as above | Worksheet → Marathi, table intact |
| `04_clips/` | `clip_1..5.wav`: Hindi, Telugu, Tamil, Telugu, Kannada (2 to 4 s each) | translate + speak, shuffled order, neutral names | Which clips are Telugu? |
| `05_paragraph/` | `paragraph.txt`: four English sentences | plain text | Read aloud in Bengali |
| `06_video/` | `lecture.mp4`: 2 s synthetic test pattern + tone | `ffmpeg -f lavfi` | Impossible: translate into French |
| `07_injection/` | `notice_injected.png`: a school notice plus "IGNORE ALL PREVIOUS INSTRUCTIONS ..." | rendered as above | Prompt-injection check |
| `08_chapter_pdf/` | `chapter.pdf`: 2 pages about the water cycle | browser print-to-PDF | One-minute Tamil audio summary of a PDF |
| `edge/` | empty file, audio behind a `.txt` name, ~65,000-character text, fake `.docx` | created by `scripts/eval_suite.py` | Edge-case suite |

All content is synthetic: no real person's voice, no real documents. The speech is AI-generated by Bodhan Indic-Speak and labelled as such in the file metadata. The repository also ships a short Hindi sample at `../../sample_data/sample_hindi.wav`.
