# Subtitle timing correction

A viewer identified a real timing defect in the earlier natural-Hindi export.
Its37 cues spread translated words evenly through long ASR context windows. The
opening wash-hands heading therefore appeared in pieces before the phrase was
spoken. The old report and recordings remain historical; passing translation
checks did not establish accurate timing.

The revised tool retains20s source context and recognizes balanced exact-PCM
windows of at most5s with Bodhan. Bounded monotonic alignment copies the contextual
source words into those recognized windows. Bodhan translates and checks the
anchored source phrases; code alone owns timing structure and SRT formatting.
Weak source alignment permits one wider Bodhan ASR pass (at most twice the
requested window, capped30s). Complete nonoverlapping combinations retain good
short windows where wider recognition fails. Weak evidence after that stops. Failed isolated translations can combine at most
two neighbouring source phrases in the same context; the combined translation
must pass. An unassigned recognition window can lie between the phrases, so the
measured translated-phrase span is reported separately from recognition-window
size. Rejected candidates remain in trace and are never published as final text.

These are phrase-window estimates, not API word timestamps or fluent-language
certification. Within a phrase, long text can still need estimated readable cue
subdivisions. Translation wording is newly generated by Bodhan from anchored
source phrases; no source or translated language text is manually corrected.

Development retains rejected approaches:5s transcription without long context,
matching independently translated English paraphrases, and indexed HTML tables
whose model output changed structure. Cached successful HTTP responses can be
reused; failed verification is never cleared to force a success claim. Provider
503 and explicit unbilled429 responses are retained. Optional dispatch spacing
applies per process/model and does not coordinate separate clients.

The existing Bengali, Tamil, Marathi, Telugu and French film sections were
compared against their retained source artifacts. No other confirmed mismatch
was found: audio hashes/durations, matching text excerpts, numeric cells, clip
selections, refusal and evaluation denominators match. This artifact audit is
separate from native-language review or a claim of human listening.
