# Dataset attribution

The demo includes excerpts of FLORES-200, released by Meta's NLLB team under Creative Commons Attribution-ShareAlike 4.0. The dataset README and citation are available in the [official repository](https://github.com/facebookresearch/flores/tree/main/flores200). The archive URL, checksum and original line identifiers are recorded in `provenance.json`.

These translations were produced by human translators for FLORES-200. This recipe uses them as references and controlled supplied outputs. It introduces labelled programmatic corruptions and synthetic wrappers as recorded per item. The resulting data files are distributed under [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Citation — NLLB Team et al., *No Language Left Behind: Scaling Human-Centered Machine Translation*, 2022.

No new human quality labels were created for the demo. The label sources distinguish assumed clean human-translation controls from known injected mutations.
