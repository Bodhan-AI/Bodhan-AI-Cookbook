# PR draft — do not publish until live validation is complete

Proposed title: `[Agentic Eng Assignment] Quality harness — Madhav N Joshi`

## Summary
Adds a translation and speech evaluation CLI with localized deterministic evidence, Bodhan round-trip checks, a configurable rubric judge and reproducible reports. Includes budgeted cached generation, human-label calibration, programmatic error injection and a review queue.

## How to run
Follow [README](../README.md). Install the package, configure the separate model keys in a local .env and run `python -m bodhan_eval --dataset data/demo.jsonl --langs hi,ta,bn --out outputs/report --generate --max-cost-inr 50`, adding the documented judge price flags. A credential-free smoke run uses `--offline` on data/smoke.jsonl.

## Architecture
See [architecture diagram](implementation_strategy.md). Cheap string checks precede bounded Bodhan back-translation/ASR and a schema-validated judge. WAV signal checks identify exact digital silence and measure clipping/silence. References provide character-bigram F1 and token alignment. Cache identities include exact inputs, model/settings, audio hashes and replicate identifiers.

## Harness design
See the [flow chart](implementation_strategy.md). Generate only missing outputs on request; sample synthesis by stable item hash. Supplied audio is always eligible for analysis. Independent checker calls overlap; repeat ASR only when the judge proposes a speech finding. Unsupported check results remain failed/skipped, never clean.

## Where the LLM is used, and why
The LLM judges meaning and localizes defects, using the versioned rubric in src/bodhan_eval/judge.py. It may quote existing text, but cannot produce corrections. Invalid schemas, quotes, spans and non-ASCII explanation prose are rejected. Identical-prompt replicates measure verdict agreement. Judge and ASR disagreement routes findings to human review.

## Bodhan models used
The live demo used hosted `indic-translate`, `indic-speak`, and `indic-transcribe`. Groq GPT-OSS 120B served as the rubric judge. The translated and transcribed outputs were generated from the user's PowerShell. See [live validation](live_validation.md).

## Results
On 537 held-out synthetic errors, deterministic checks detected 319 (59.4%). Adding a separate Bodhan ASR comparison against the parent clips increased detection to 471 (87.7%). It classified 86/92 speech omissions and 70/92 repetitions correctly. Combined localization overlap was 65.4%, below the 70% target. The paired speech check does not provide audio timestamps. Category accuracy was 79.9% on the eligible localized detections. This experiment requires a baseline clip transcript per item. Human calibration and clean-item false alarms were not measured.

The [demo report](../sample_report/live_demo/summary.md) includes per-language counts and per-category metrics. All 12 judge checks in a targeted injected-case run failed due to rate limits, HTTP 400 or rubric validation. Human review was skipped, so the human-labelled subset remains incomplete.

Phase 3 adds blind content-bound annotation, generation receipts, strict assessed-population benchmarks and a read-only [evidence audit](phase3_readiness.md). Error-level detection is reported separately from item-level detection, and human versus injected evaluation groups remain distinguishable. The [workflow](phase3_workflow.md) gives reproducible preparation and validation commands. A readiness audit is not evidence of live model quality by itself.

## Trade-offs and known limitations
Systematic ASR and judge errors remain possible. Shared scripts cannot establish language identity. Literal numeric checks can misread number words, unit conversions and grouping conventions. Calibration only tunes judge-confidence thresholds; structural checks remain transparent fixed rules. General mistranslation injection requires reviewed term correspondences and is not fabricated.

## Cost and runtime
Conservative request reservations include retry attempts; execution metadata is outside deterministic reports. Live per-100-item cost/runtime with and without speech: **pending**. A repeatable benchmark utility verifies cache replay using artifact hashes.
