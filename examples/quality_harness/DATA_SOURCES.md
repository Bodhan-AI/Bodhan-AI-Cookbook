# Data sources and licensing

## English sources (`data/sources_en.jsonl`)
All English source sentences are the candidate's own composition, written specifically for this
assignment and released into the public domain under **CC0 1.0**. They are short, factual,
textbook-style statements plus a few Markdown tables and LaTeX formulas, chosen to exercise the
checks (numbers, units, entities, formatting, multi-sentence coverage). No third-party text is
copied, so there are no attribution constraints.

If you prefer real-world corpora, `scripts/make_sources.py` can be pointed at openly-licensed
collections instead, for example:
- OpenStax textbooks (CC BY 4.0)
- Simple English Wikipedia (CC BY-SA 4.0)
- Project Gutenberg (public domain in the US)
Keep each source's license and attribution here if you do.

## Indic translations (`data/demo.jsonl`)
The current `data/demo.jsonl` was generated using hosted Indic-Translate, then perturbed by the
programmatic injector. It has 108 rows and 54 injected examples. Unperturbed translations have not
been individually reviewed and should not be represented as human-verified clean examples. Confirm
the source authorship and license claims above before publishing.

## Offline fixture (`data/tiny10.jsonl`)
`data/tiny10.jsonl` is a 10-item fixture used by the end-to-end test and `make run-demo`. Its
short Indic strings were written by the candidate purely as offline test data and are labelled
`"annotator": "candidate"`. It exists so the harness and its determinism can be verified with no
network or keys. It is **not** the scored demo dataset; the real demo dataset is generated by
Bodhan via `make demo`.

## Audio
Generated audio (WAV) is never committed (see `.gitignore`). Regenerate it at run time with
`--generate`, or point `audio` fields at local files.

## Human labels
Any label added by the candidate carries `"annotator": "candidate"`. Injector labels carry
`"label_source": "injector"`. This keeps candidate/injector labels distinct from the graders'
hidden labels.
