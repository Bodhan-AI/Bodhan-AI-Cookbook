01

Three things make this hard

Anyone can diff two strings. The difficulty is that the obvious signals are all unreliable in a different way.

No references

Most content has nothing to compare against

Real translations arrive without a gold reference. Reference-free checks — script, numbers, structure, entities — have to carry the load, which means they must be precise enough to trust on their own.

Noisy checkers

Back-translation makes its own mistakes

A round trip through Indic-Transcribe or a back-translation introduces errors that look exactly like system errors. Separating checker noise from real defects is the difference between a usable report and a misleading one.

Judge drift

LLM judges are fluent, and that flatters

A judge favours confident prose and behaves differently per language. Its verdicts have to be measured for consistency, not assumed — so the harness re-asks with the cache bypassed.

02

Cheap checks first, paid checks where they pay

Every stage is gated by cost. Deterministic checks run on every item for free; the judge and the audio round-trip are reached only when an item justifies them.

05

What it does not do yet

Stated plainly, because a report that hides its gaps is worse than one that names them.

Never run against the live API

Endpoint paths are OpenAI-compatible assumptions. Confirm /audio/speech and /audio/transcriptions against Bodhan's docs on the first real run.

Omission localization is approximate

A dropped clause has no position in the output, so the flag points at the nearest anchor or the head of the text.

Transliterated entities are invisible

A wrongly transliterated name passes every current check. Detecting it needs a transliteration model, which is out of scope.

Speech checks need PCM WAV

Other containers must be converted with ffmpeg before scoring; the harness reports undecodable audio rather than failing.

Built for the Bodhan AI Agentic Engineer take-home. Bodhan models only for translation, synthesis and recognition — no other speech or MT system is called anywhere in the harness.
