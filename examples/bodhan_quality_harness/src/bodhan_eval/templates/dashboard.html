🏗️ Multi-Tier Harness Architecture

          

          

            
Tier 0 — Free Deterministic Checks (Every Item):

            • script.wrong_script: Char-script ratio on prose (ignores LaTeX/tables).

            • script.untranslated: Exact English preservation check.

            • numbers.*: Digits and significant numeric preservation.


            
Tier 1 — Calibrated Statistical Checks:

            • length.*: Dynamically swept word-ratio thresholds.

            • length.repeat: Script-agnostic n-gram phrase loop detector.

            • terms.entities: Acronym and technical token consistency.


            
Tier 2 — LLM Judge (Escalated Only):

            • Rubric-constrained evaluation of meaning-level mistranslations at temperature 0.


            
Tier 3 — Speech Signal & Round-Trip:

            • Signal duration, silence fraction, clipping, and Indic-Transcribe back-checking.

          

        


        

          

            
📜 Ground Rules & Safeguards

          

          

            
✓ Zero LLM Text Generation: LLM judges evaluate and localize; they never write or correct Indian-language text.

            
✓ Determinism & Caching: Every model response is SHA-256 hashed and cached by exact input. Reruns are byte-identical and cost ₹0.

            
✓ Hard Budget Ceilings: --max-cost-inr enforces budget limits without crashing the run.

            
✓ Clean Secrets Hygiene: Zero keys committed in git; masked safely in UI.
