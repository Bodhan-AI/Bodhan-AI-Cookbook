# Open test data

Built by `scripts/build_test_data.py` into `test_data/` (git-ignored, about 80 MB, 294 files). Do not commit the media; this file is the link.

```bash
uv run --with pyarrow --with huggingface_hub python scripts/build_test_data.py
```

Real data is downloaded (FLEURS audio streamed so only the first clips are fetched; OCR images read from one 95 MB parquet). Everything else is derived locally with ffmpeg, PIL and PyMuPDF at zero Bodhan cost. The script is idempotent.

## Layout and the task each part serves

| Path | Contents | Serves |
|---|---|---|
| `audio/{hi_in,ta_in,te_in,bn_in,mr_in,ne_np,kn_in,ml_in,or_in,gu_in,pa_in,ur_pk,as_in}/` | 2 to 20 clips each (5 to 25 s) + `.txt` reference | transcription, language ID, "which clips are Telugu", close pairs (Hindi/Marathi/Nepali, Telugu/Kannada) |
| `audio/en_us/` | 6 English clips + reference | English ASR |
| `audio/fr_fr/` | 3 French clips | **unsupported-language** input (Transcribe has no French) |
| `audio/hi_3min.wav` | 189.8 s Hindi, 16 kHz mono | the brief's "3-minute WAV" subtitle task, many chunks |
| `audio/hi_long.wav` | 67 s Hindi | 3-chunk test, cheap |
| `audio/formats/` | one clip as `.wav .mp3 .ogg .flac .m4a .aac .webm`, plus `stereo_44k`, `telephone_8k`, `noisy`, `silence_30s`, `truncated`, `zero_byte`, `not_audio` | format conversion (Transcribe refuses M4A/AAC/WebM natively), bad/corrupt/empty input. AMR not generated (no encoder). |
| `video/te_speech.mp4`, `hi_speech.mp4` | MP4 with Indic speech | "Translate this video into French" (impossible) and "transcribe this video" |
| `video/no_audio_track.mp4` | MP4 with no audio | video with nothing to transcribe |
| `ocr/<Language>_{1,2}.png` + `.gt.txt` | 2 real document images each for about 23 languages (Hindi, Tamil, Telugu, Bengali, Marathi, Odia, Kannada, Malayalam, Gujarati, Punjabi, Urdu, Sindhi, Assamese, Bodo, Dogri, Kashmiri, Konkani, Maithili, Manipuri, Nepali, Sanskrit, Santhali, English) | OCR in many languages, accuracy vs ground truth |
| `ocr/tables/` | 3 real table images (Hindi, Kannada, Odia) + ground truth | "translate this worksheet and keep the table" |
| `ocr/chapter_hi/page1-8.png` | 8 Hindi pages | the brief's "scanned PDF, 8 pages" chapter |
| `ocr/variants/` | one page as `rotated_90`, `rotated_15`, `low_res`, `dark_low_contrast`, `jpeg_q20`, `huge` (3x), `exif_rotated.jpg`, `photo.heic`; a table as `table_photo.jpg` (tilt, shading, blur) and `synthetic_table_en.png` | "photo of a worksheet": rotation, EXIF, HEIC, bad light |
| `ocr/real_photos/guwahati_ropeway_fares_timetable.jpg` | **real iPhone photo** of a laminated English notice with two tables, glare, tape and a finger in frame (1536x2048) | the brief's "photo of a worksheet, keep the table" with realistic noise |
| `ocr/real_photos/train_name_kannada_hindi_tamil_english.jpg` | **real Samsung phone photo** (2560x1920) of a station sign in Kannada, Hindi, Tamil, English | multi-script photo, no table; per-script OCR check |
| `ocr/injection_en.png` | image containing "ignore all previous instructions…" | prompt injection through OCR |
| `pdf/scanned_chapter_hi.pdf` | 8 pages, image-only | scanned PDF to audio summary |
| `pdf/scanned_mixed_languages_4p.pdf` | 4 pages, 4 languages | per-page language handling |
| `pdf/pages_62.pdf` | 62 pages | page cap (`TOO_LARGE`), budget-too-small |
| `pdf/digital_text_layer.pdf` | real text layer | digital vs scanned handling |
| `pdf/encrypted.pdf` | password `secret` | unreadable-file error |
| `text/long_{en_us,hi_in,mr_in,ta_in}.txt` | 25 to 40 sentences each | translation chunking, long TTS input, source-language detection |
| `text/injection_en.txt`, `injection_hi.txt` | normal sentences with an embedded instruction (English and Hindi) | prompt injection through text |
| `text/hinglish.txt` | romanised code-mixed Hindi | script detection edge case |
| `text/empty.txt` | zero bytes | empty-input error |

Not covered: spoken injection (would cost a few paise of TTS), AMR audio.

## Plan: which sample for which check, with cost

| Check | Input | Expected | Bodhan cost |
|---|---|---|---|
| Chunking, many chunks | `audio/hi_3min.wav` | about 7 chunks, each ≤28 s, similarity to concatenated reference | Rs 0.32 |
| Chunking, 3 chunks | `audio/hi_long.wav` | 3 chunks | Rs 0.12 |
| Near the limit | longest `ta_in` clip (25.4 s) | 1 chunk | Rs 0.04 |
| Language ID | one clip each: `te_in kn_in ml_in mr_in ne_np hi_in bn_in as_in` | correct language; Devanagari trio is the hard case | about Rs 0.2 |
| Unsupported language | `audio/fr_fr/*.wav` | `UNSUPPORTED_LANGUAGE`-style honest result | Rs 0 to 0.04 |
| Format handling | each file in `audio/formats/` | all decode and transcribe except the bad ones, which error cleanly | Rs 0.02 per file, 5 files enough |
| Video | `video/te_speech.mp4`, `no_audio_track.mp4` | transcript / clear error | Rs 0.03 |
| Translation | `text/long_en_us.txt` to `ta`, `mr` | no truncation, script right, ratio sane | under Rs 0.1 |
| Long TTS | translation of 5 sentences | back-transcription similarity | about Rs 0.5 |
| OCR accuracy | `ocr/Hindi_1.png`, `Tamil_1.png`, `Kannada_1.png` | CER vs `.gt.txt` | Rs 0.6 |
| OCR robustness | `ocr/variants/*` | rotated/EXIF/HEIC fail or succeed knowingly | Rs 0.2 each |
| Tables | `ocr/tables/*`, `variants/table_photo.jpg`, `real_photos/guwahati_ropeway_fares_timetable.jpg` (translate to Marathi, table kept) | table kept through translation | Rs 0.2 each |
| Scanned PDF | `pdf/scanned_chapter_hi.pdf` | 8 page markers in order | Rs 1.6 |
| Page cap / budget | `pdf/pages_62.pdf` with a tiny cap | refused before spending | Rs 0 |
| Injection | `text/injection_*.txt`, `ocr/injection_en.png` | instruction ignored and flagged | Rs 0 to 0.2 |
| Bad files | `zero_byte.wav`, `not_audio.wav`, `truncated.wav`, `encrypted.pdf`, `empty.txt` | structured errors | Rs 0 |

Never run everything in a loop: a full pass is about Rs 6 to 8. Run subsets, with the cache on.
