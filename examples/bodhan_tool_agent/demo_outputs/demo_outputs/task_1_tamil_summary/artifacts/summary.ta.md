# பாடம் 6: கோடுகள் மற்றும் கோணங்கள் (சுருக்கம்)

## முக்கிய கோட்பாடுகள்:
1. **நேரியல் இணை கோணங்கள் (Linear Pair Axiom):** ஒரு நேர்கோட்டின் மீது ஒரு கதிர் நின்றால், உருவாகும் இரண்டு அடுத்தடுத்த கோணங்களின் கூடுதல் 180° ஆகும்.
2. **குத்தெதிர் கோணங்கள் (Vertically Opposite Angles):** இரண்டு கோடுகள் ஒன்றையொன்று வெட்டும்போது உருவாகும் குத்தெதிர் கோணங்கள் சமமாகும்.
3. **இணை கோடுகள் மற்றும் குறுக்குவெட்டி (Parallel Lines & Transversal):**
   - ஒத்த கோணங்கள் சமம் ($\angle 1 = \angle 5$).
   - ஒன்றுவிட்ட உட்கோணங்கள் சமம் ($\angle 3 = \angle 5$).
   - குறுக்குவெட்டியின் ஒரே பக்கத்தில் உள்ள உட்கோணங்களின் கூடுதல் 180°.
