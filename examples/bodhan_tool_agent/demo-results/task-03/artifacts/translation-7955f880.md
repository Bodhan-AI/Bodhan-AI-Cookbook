१. उद्गारवाचक शब्द म्हणजे काय? (व्याख्या)

उद्गारवाचक शब्द हा एक "भावना व्यक्त करणारा शब्द" आहे! तो एक लहान, उत्साहवर्धक शब्द आहे जो आनंद, दुःख, राग किंवा आश्चर्य यांसारख्या अचानक निर्माण होणाऱ्या भावना दर्शवतो.

$\bullet$ **सुवर्ण नियम**: उद्गारवाचक शब्दांच्या बरोबर नेहमी उद्गारचिन्ह ($!$) वापरले जाते.
