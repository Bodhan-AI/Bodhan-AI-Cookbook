# Demo task prompts

These are prompt templates, not claimed demo results. Use only input media you have permission to process and keep generated files in the ignored run output directory.

1. OCR a scanned PDF, summarize its English content, translate the summary into Tamil with Indic-Translate, and create verified Tamil speech.
2. Transcribe a Hindi WAV and produce a transcript. Do not request SRT timestamps because the verified transcription API does not provide them.
3. OCR a worksheet photo and translate the extracted text into Marathi while preserving table structure where the OCR output contains it.
4. Transcribe a directory of short audio clips, identify clips whose Bodhan transcript is Telugu, and translate those transcripts into English.
5. Translate an English paragraph in a text file into Bengali and generate speech using a documented Bengali voice.
6. Ask for French dubbing of an MP4. Explain that video dubbing and French are unsupported by the documented Bodhan speech language list; produce no fabricated audio.

Record actual run costs, output paths, and traces before describing any task as passed.
