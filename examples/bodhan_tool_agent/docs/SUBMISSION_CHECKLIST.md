# Bodhan AI Cookbook — Submission Checklist

This checklist tracks all submission requirements outlined in [`Agentic Engineer Take-Home Bodhan Tool Server and Task Agent.md`](../Agentic%20Engineer%20Take-Home%20Bodhan%20Tool%20Server%20and%20Task%20Agent.md).

---

## 1. Ground Rules & Safety Checks
- [x] **Zero Prohibited Models**: Only Bodhan Indic models (`indic-transcribe`, `indic-translate`, `indic-speak`, `indic-ocr`) are used. No Whisper, Tesseract, IndicTrans2, or cloud APIs anywhere in the code.
- [x] **LLM Boundary Protection**: The LLM emits only abstract step IDs, English rationales, and plan structures. No raw filesystem paths, timestamps, pricing calculations, or Indic characters are generated by the LLM.
- [x] **Secrets Sanitized**: No `.env` or API keys committed to Git. Clean `.env.example` provided.
- [x] **No Demo Special-Casing**: The agent operates via generic classification heuristics (media kind, duration, page count, verb-to-type consistency).
- [x] **Honest Refusal on Impossible Tasks**: Unsupported foreign languages (e.g. French, German) and missing files terminate immediately with `status="impossible"`, ₹0.00 spend, and zero fabricated artifacts.

---

## 2. Engineering & Code Quality
- [x] **FastMCP Stdio Server**: Pure stdout for JSON-RPC messages; all logging strictly routed to `sys.stderr`. Tested via off-the-shelf MCP Inspector.
- [x] **Autonomous Task Agent CLI**: Strictly matches CLI specification:
  ```bash
  python -m bodhan_agent --task "<task>" --files <input_dir> --out <out_dir>
  ```
- [x] **Model Limit Absorption**:
  - Audio: Silence chunking ($\ge 250\text{ms}$) at 25s target with timestamp remapping.
  - Translation: 32K context window pagination along structural Markdown boundaries.
  - OCR: PDF page rendering at 200 DPI via PyMuPDF with page loop.
  - TTS: 5,000-character cap with official Indic voice mapping (`Kavya` / `Ankur`).
- [x] **Concurrency & Caching**:
  - `asyncio.Semaphore(4)` concurrency limit.
  - SHA256 in-run caching at ₹0.00 cost for duplicate requests.
  - Exponential backoff retries via `tenacity` on HTTP 429 and 5xx errors.
- [x] **Dual-Key LLM Failover**: Automatically fails over to `LLM_API_KEY_SECONDARY` on Groq HTTP 429 rate limits.
- [x] **Automated Verifications**: Audio back-transcription, table parity, translation coverage, and monotonic SRT structure.
- [x] **Prompt Injection Defense**: Untrusted content scanned and wrapped in delimiter blocks (`<UNTRUSTED_CONTENT_START>`).
- [x] **Unit & Integration Test Suite**: 77 / 77 tests passing locally (`pytest -q` green in < 7s with all Bodhan HTTP mocked).
- [x] **Live Evaluation Matrix**: 10 / 10 live test cases passing on real Bodhan and Groq APIs with total spend of ₹0.4492 (well within ₹2.00 ceiling).
