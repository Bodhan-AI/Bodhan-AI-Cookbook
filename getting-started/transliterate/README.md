# Transliteration

Convert text between native and roman script while keeping pronunciation, in both directions.

| | |
|---|---|
| Model | `indic-transliterate` |
| Endpoint | `POST /transliterate` |
| Notebook | [transliterate.ipynb](transliterate.ipynb) |

## Setup

```bash
pip install -r requirements.txt
export BODHAN_API_KEY=<your key from https://console.bodhan.ai>
```

## Run

```bash
jupyter notebook transliterate.ipynb
```

Reference: [console.bodhan.ai/api-docs](https://console.bodhan.ai/api-docs/)
