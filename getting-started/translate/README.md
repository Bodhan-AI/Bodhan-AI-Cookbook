# Translation

Translate between English and 22 Indian languages, choosing native, roman or code-mixed output, and fan one text out to many languages.

| | |
|---|---|
| Model | `indic-translate` |
| Endpoint | `POST /translate` |
| Notebook | [translate.ipynb](translate.ipynb) |

## Setup

```bash
pip install -r requirements.txt
export BODHAN_API_KEY=<your key from https://console.bodhan.ai>
```

## Run

```bash
jupyter notebook translate.ipynb
```

Reference: [console.bodhan.ai/api-docs](https://console.bodhan.ai/api-docs/)
