# Synthetic Sample Documents

This folder contains small (< 2 KB each), synthetic documents in Indian languages used for demonstrating and testing the Bodhan LangChain integration.

## Files

- **`sample_hindi_scholarship.pdf`**: Synthetic circular in Hindi describing an educational scholarship scheme.
- **`sample_tamil_agriculture.pdf`**: Synthetic notice in Tamil describing an agricultural insurance program.
- **`sample_bengali_health.pdf`**: Synthetic notice in Bengali describing a rural health clinic initiative.

All documents are synthetic and contain no real personal data, proprietary information, or copyrighted material.
