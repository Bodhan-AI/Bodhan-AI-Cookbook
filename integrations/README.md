# Integrations

Guides for using Bodhan models inside third-party frameworks and platforms. Each integration is a folder with a notebook or a small project and its own README.

| Integration | Status | What it shows |
|---|---|---|
| [OpenAI SDK](openai_sdk/) | ready | Using the official `openai` Python package against Bodhan's OpenAI-compatible `/v1` routes |
| LiveKit | wanted | Real-time voice agent with `indic-transcribe` and `indic-speak` |
| Pipecat | wanted | Voice pipeline with Bodhan STT/TTS services |
| Twilio / Exotel | wanted | Phone voice agent over media streams |
| n8n | wanted | No-code transcription and translation workflows |
| Vercel AI SDK | wanted | Bodhan as a custom provider in a Next.js app |
| LangChain / LlamaIndex | wanted | Translation and OCR as document loaders / tools |

"Wanted" rows are open for contribution. Open a [recipe proposal](https://github.com/Bodhan-AI/Bodhan-AI-Cookbook/issues/new?template=recipe_proposal.md) to claim one.
